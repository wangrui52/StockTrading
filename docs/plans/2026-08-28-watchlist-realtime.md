# 自选股实时报价刷新

**目标：** 自选股页增加“刷新自选股行情”，只查询点击时已加入自选的股票。报价及时间独立于日线信号、风险与提醒。

## 设计和实施

1. 复用实时报价采集和进度逻辑，为任务增加 `scope`、点击时固定的 `requested_symbols`；旧任务迁移为 `market`。全市场和自选股使用各自的冷却、任务状态和快照（id 1/2），不能互相覆盖。
2. API 使用 `scope=watchlist`。空自选列表返回明确错误且不建立任务；请求只发送股票代码，不发送分组、笔记等用户数据。失败保留上次快照。
3. 自选接口批量读取自选快照并附加 `realtime` 字段，原有日线字段不变。前端提供按钮、进度、错误和最后刷新时间；成功后自动重读自选列表。无实时报价时明确显示“日线参考”，不冒充实时；旧报价标注原时间。
4. 定向测试先覆盖：只请求自选、空列表、点击后名单固定、全市场隔离、失败保护、刷新后自动展示、缺失报价回退标记。
5. 运行后端/前端回归、类型检查、构建和迁移验证；更新本机服务，验证真实报价和日线不变。保留此前未提交改动，不 commit/push。

# Goal Contract

## 最终目标

按照 PRD V1.1 实现可在本地完整运行、未来可部署远程服务器的 A 股日线辅助决策系统。

## 交付物

- 独立的 FastAPI 后端和 React/TypeScript 前端。
- SQLite 本地数据、AkShare adapter、指标与信号引擎。
- 看板、详情、筛选、自选、提醒、报告及 PRD P1 功能。
- 单元、集成、契约和端到端测试，前后端覆盖率不低于 70%。
- Docker Compose、Nginx 和部署运维文档。

## 成功标准

- PRD 的 P0/P1 功能均有实现和当前证据。
- 本地真实进程可以完成核心用户流程。
- 前后端源码、依赖和构建隔离，只通过 REST interface 通信。
- 默认测试与 E2E 通过，核心状态机和错误路径有业务断言。
- 远程部署配置可构建、启动并通过 healthcheck。

## 范围内

PRD V1.1 的全部功能、测试、本地运行和远程部署基础。

## 范围外

自动交易、分钟级实时行情、AI 预测、策略回测、多用户、移动 App、实际生产服务器上线。

## 硬性约束

- 前后端代码隔离。
- TDD 实现，覆盖率不低于 70%。
- 本地先跑通；未来远程部署不需要重写业务代码。
- 不把局部完成描述为整体完成。

## 可协商约束

可逆技术决策默认使用推荐方案，不需要逐项打扰用户；必须记录依据。

## 停止条件

仅在用户要求暂停、遇到三轮无法解除的外部阻塞，或所有完成证据齐全时停止。

## 当前不做

不执行生产部署，不配置真实券商或交易操作。
